# Sales & Revenue Analysis Dashboard

## Project Overview
This project is a Sales and Revenue Analysis Dashboard created using Tableau Public. It helps analyze sales data, track revenue trends, identify top-performing products, and compare sales across different regions.

## Objectives
- Analyze total revenue and quantity sold.
- Visualize monthly revenue trends.
- Identify top-performing products.
- Compare sales across different regions.
- Provide interactive filters for better analysis.

## Tools and Technologies
- Tableau Public
- Microsoft Excel
- CSV Dataset

## Dataset
The project uses a sample sales dataset containing order ID, order date, product, category, quantity, unit price, region, and revenue.

## Key Features
- Total Revenue KPI
- Total Quantity Sold KPI
- Monthly Revenue Trend
- Top Products Analysis
- Sales by Region
- Interactive Region Filters

## Expected Outcome
The dashboard provides clear visual insights into sales performance and helps users understand revenue trends and product performance.
